## Description
This script provide all the statistical analyses tested on the modern pollen assemblages from the Tajikistan and Uzbekistan Surface Data Base :
- `Pollen_surf.R`: clean of the modern pollen assemblages and multivariate analysis (PCA and RDA pollen-based);
- `Veget.R`: vegetation plots cleaning and analysis (TWINSPAN, Correspondance Analysis, PCA, RDA vegetation-based) and comparison with the pollen data (pollen vs. vegetation diagram, Davis' Indices, pollen representativeness maps...);
- `Pollen_fun_trans.R`: pollen-based quantitative reconstructions using transfer function (WA-PLS), modern analogue technique (MAT) and two machine-learning approaches (RF and BRT);
- `Pollen_FT_plot.R`: graphical visualisation of the climate reconstruction applied on the Aral-86 sequence (Aleshinskaya, 1991)
- `Trait_local.R`: methological workflow followed to cross plant functional traits data with both pollen assemblages and vegetation plots from the TUSDB and statistics (linear regressions, PCAs and Procrustes Analysis).

## Structure
- `data/raw/` – original raw datasets (not modified)
- `data/processed/` – cleaned datasets for analysis
- `scripts/` – ordered scripts for full reproducibility
- `results/` – figures, tables, models generated by scripts

## Install/run R
1. Install [R](https://larmarange.github.io/analyse-R/installation-de-R-et-RStudio.html)
2. It is easier to use [Rstudio](https://posit.co/downloads/)
3. Download this GitHub repository from ZIP file (by clicing on the green button `<> Code` beyond.
4. Change the Boolean variables (e.g., `Import = T`) to import, reconstruct past environmental variables and drow the figure related to the article (Dugerdil et al., 2025b)
